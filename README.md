# Foodcraft Caterers

Static luxury catering website for Foodcraft Caterers, Agra. No customer data is stored; enquiries are composed locally and handed to WhatsApp only after review.

## Commands

- `npm run check` — validate critical content and assets
- `npm run build` — generate `dist/`
- `npm run dev` — local preview on port 4173

Before production launch, replace the example sitemap domain, confirm the public email and map listing, and replace AI-created development imagery with authorized Foodcraft event photography where available.
